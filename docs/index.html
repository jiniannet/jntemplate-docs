JNTemplate ​

A cross-platform, high-performance and highly flexible text parsing engine (template engine).

Overview ​

JNTemplate is a text parsing engine (template engine) written entirely in C#. It can generate any text-based content, including but not limited to HTML, XML and CSS, keeping the presentation layer separate from back-end code logic. It also gives you an alternative to WebForms and Razor!

All of the JNTemplate source code is open source and has minimal dependencies, which makes migration and cross-platform support easy. Under the terms of our open source license, you are free to use, distribute and build commercial products with it (see License.txt for details).

Since version 2.0, the engine has been fully upgraded to a compiled template engine and can run on .NET Framework, Mono, .NET Core and .NET 5.

Features ​

  • Faster: an efficient IL-based template pre-compilation mechanism brings runtime speed close to native code.
  • Simpler: an easy-to-learn syntax — with some front-end/back-end background you can get started in as little as 10 minutes.
  • More convenient: every option can be configured freely, and you can extend the engine with your own tags.
  • Freer: free for commercial use with no fees at all, and all source code is fully open.
