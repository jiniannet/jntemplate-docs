Installation ​

You can get JNTemplate in the following ways.

Get the release from NuGet ​

  • In Visual Studio Open Visual Studio, create a new project, then click the menu bar => Project => Manage NuGet Packages (Alt+G, N) and search for JNTemplate.

  • From the command line

bash
> Install-Package JinianNet.JNTemplate

or (NET CORE)

bash
> dotnet add package JinianNet.JNTemplate

Build from source ​

  • WINDOWS:
batch
> git clone https://gitee.com/jiniannet/jntemplate.git
> build/build.bat
  • LINUX:
bash
> git clone https://gitee.com/jiniannet/jntemplate.git
> cd build
> ./build.sh

Repository mirrors ​

  • China: Gitee
  • International: GitHub

Recommendations ​

  1. We strongly recommend getting our releases from the NuGet package, so that you are notified of new versions in time and receive better technical support.
  2. You can use the PublicKeyToken 2b90a65531efdba4 to verify that a release is an official one.
