# JNTemplate
***
**About JNTemplate**

The Chinese name of JNTemplate is "极念模板引擎" (Ji Nian Template Engine). "JN" comes from the pinyin initials of 极念: 极 (jí) means extreme or ultimate — the best; 念 (niàn) means idea or concept. So the name can be understood as "the best idea, the greatest concept".

JNTemplate is a text parsing engine written entirely in C#. It can generate any text-based content: you can use it to render web templates, or as a code generator, an XML document generator, or for any other purpose you can think of.


**Why choose JNTemplate**

1. Stable: we have kept iterating since the .NET Framework 2.0 era, continuously improving features and providing technical support, and its stability has been validated by the community.
2. Fast: code is compiled with IL emit, and it performs well in both compilation and execution speed.
3. Free: fully usable for commercial purposes, with no fees at all.
4. Simple: concise and easy to use, with a low learning curve.


**Why JNTemplate when Razor exists?**

As Microsoft's official view engine, Razor is undoubtedly the best choice in ASP.NET MVC. In some scenarios, however, we may need a more flexible and lightweight template engine, so the two do not conflict.
